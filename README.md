# Desktop Escape

A browser platformer where you drag desktop windows into place and jump across them to reach the exit. The game includes 50 levels and the original soundtrack, Midnight Checksum.

Open index.html to play. Use A/D or the arrow keys to move, Space to jump, and the mouse to drag windows. Esc pauses and R retries. The soundtrack starts after the first interaction, and the Sound setting controls music and effects.

For itch.io, zip index.html, style.css, game.js, levels.js, and Midnight-Checksum.wav together with index.html at the root. Upload the ZIP as an HTML game.
